## 工程边界

- 正式源代码放在 `src/AileArc.Client`；压力测试入口仅作为自动自检参数，不进入用户界面。
- 视觉复用已确认的暖石墨控件模板；原生 TextBox 的 IME、DataGrid 行虚拟化和 UI Automation 保持。
- Core、Worker、Engine 的公共接口和安全规则作为迁移基础；UI 不直接调用引擎，不绕过 Core 写入目标文件。
- 使用现有 `LanguageService` 和嵌入资源。应用字符串不分散在 XAML/C#，新资源键保持中英文一致。
- 暂时提供独立 `Build-Client.ps1`；现有 `Build.ps1`/`Package.ps1`/安装器继续指向已覆盖更多功能的旧客户端，直到 P4 验收。
- 前期启动参数接受归档路径，以及内部语言重启使用的受限会话参数（路径和编码，无密码）；尚未实现的 Shell 动作不得静默当作普通路径处理。
- 窗口在异步操作中维护取消和世代校验；失败保持之前会话，密码不进入日志/命令行/持久设置。

## 待解决的交互差异

- DataGrid 默认 Ctrl+方向键按表格边界跳转；后续根据文件管理器习惯统一键位。
- 多 DPI、多输入法、完整读屏和长时间滚动继续验证，不能因单机验证通过而宣称全部平台行为一致。
- 真实分页选择暂限定当前页；跨页选择需明确身份与过滤变化语义后实现。

## P1 交付与验证记录

入口：`./scripts/Build-Client.ps1 -Test -Run`；打开指定归档可附加 `-Archive 'D:/Archives/example.zip'`。输出 `.artifacts/client/Release/AileArc.Client.exe`。

- 正式窗口默认空白欢迎页，已移除生成样本按钮和框架验证标签；压力数据仅用于自动自检。
- 复用 DesktopBridge 中无 UI 依赖的 ArchivePresentation（不是 WebView2 宿主）；Core/Worker 接口与预算不变，读取/索引/查询在后台执行。
- 密码输入、错误后重试、ZIP 编码重读、名称/大小排序与降序已接通。失败保留原会话；密码只留在当前窗口内存，不进入设置或命令行。
- 复用 LanguageService/.resw，新增客户端资源的中英文键和占位符一致。实际测试保存英文后当前界面不变，重启显示英文并恢复归档，再切回简体中文；测试结束已恢复简体中文。
- 实机使用生成的文件名加密 7Z 验证错误密码、正确密码读取；ZIP 样本验证名称降序、UTF-8 重读和完成后控件恢复。英文编码标签宽度与底部提示换行已调整。
- 两种语言的实际 WPF 控件自检通过：无样本启动、真实 Worker、隐式目录、十万项选择/末行、会话替换和读取失败保持旧会话。首次测试在无会话的禁用列表上检查末项失败，改为先建立真实会话并等待布局后通过；未省略这次失败。
- 现有 98 项 .NET 回归通过，包含两种语言资源键/占位符匹配。CI 增加 Build-Client.ps1 -Test。
- 同进程具备路径重复激活、另包新窗口及语言重启恢复路径的基础入口；跨进程激活、文件身份别名去重和写入任务关闭保护仍归 P3，不能将基础入口描述为完整生命周期迁移。
- 语言重启恢复每个窗口的文件名编码。内部会话参数最多 64 个归档、24,000 字符，拒绝未知字段及不支持编码；不使用 Shell 拼接，不传递密码。

以上为 P1 时点记录。P2 已继续接入下列能力；创建、恢复清理和完整生命周期仍待 P3，安装/Shell 待 P4。没有改变文件关联或创建正式 Release。

## P2 交付与验证记录（2026-10-24）

- 首先确认上一轮 `ad5f749` 的完整 CI 成功（run 39891538144）。
- 统一解压对话框提供全部、所选、智能解压、压缩包所在文件夹四种模式，以及成功后打开目录选项。所选目录通过 ArchiveSelection 按 Entry ID/目录边界展开，保持内部路径。
- 提取沿用浏览快照身份、密码与编码，调用现有 Core/Worker；冲突支持重命名/跳过/替换、应用到后续及取消。取消保留完成项，失败列出路径/原因，不报全成功。来源标记、路径/重解析点校验和 4 GiB 预算沿用 Core。
- 双击普通文件或“打开文件”准备单文件工作副本后调用 Windows ShellExecute；无关联走系统打开方式，不修改默认关联。可执行内容先确认，拒绝或准备取消后不启动应用；单文件继续限制 256 MiB。准备中界面拒绝重复请求，完成后复用副本而不覆盖外部修改。
- 进程共享 WorkCopyStore；每 10 秒后台检查本窗口打开的副本，提示与任务结果分开。“工作副本”可读取持久记录、检查状态、打开位置、另存为。所有副本跨关闭保留，不自动回写或清理。
- 有任务关闭时选择等待或取消并退出，等待 Worker 清理后才关闭；修改/不可读取副本需确认保留退出。语言重启逐窗口执行同样保护，检查期间禁止启动新任务。跨进程交接、身份别名与统一恢复协调仍属于 P3。

- 实机通过公开生成 ZIP 验证解压落盘、双击文本交给当前默认 Zed、编辑保存后的修改提示、副本管理状态、保存选择器和关闭保留提示。另存写入由真实 Core 自检验证；未宣称所有系统文件关联及无关联对话框均已实测。
