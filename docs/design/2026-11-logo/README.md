# AileArc 暖石墨 Logo 候选

后续按指定模型生成的 [Image 2.6 候选 A2、B2、C2](image-2.6/README.md) 有单独的三场景对照与生成记录。本页保留首轮 A、B、C 供比较。

三份提案使用同一标题栏、图标尺寸和横幅版式，便于比较图形本身。正式资源在选定方案后另行更新。

| 候选 | 识别要素 | 场景对照 | 设计文件 |
|---|---|---|---|
| A · 折带 | 浅色 A 字与右下角的铜色回折呼应现有标识 | [查看折带](fold-proof.png) | [透明标记](fold-mark.png) · [完整 Banner](fold-banner.png) |
| B · 双层档案夹 | 两个错位的索引耳，小图标中仍能分辨上下两层 | [查看双层档案夹](drawer-proof.png) | [透明标记](drawer-mark.png) · [完整 Banner](drawer-banner.png) |
| C · 拉链印 | 铜色方印中间留出咬合缝，上方纸色拉头提示压缩用途 | [查看拉链印](clasp-proof.png) | [透明标记](clasp-mark.png) · [完整 Banner](clasp-banner.png) |

标记分别使用内置 ImageGen 生成，保留透明背景。工具未提供模型版本回执。每张场景图包含以下三项。

- 用本轮 WPF 客户端实际标题栏控件，按打开归档时的布局和 22 DIP 图标位置渲染。
- 为候选生成多尺寸 ICO，临时赋给独立窗口。在本机 Windows 11 的 Explorer 任务栏中定位并截取该窗口的按钮；右侧另列 16、24、32 像素的 ICO 图层。将场景图按原尺寸打开可查看像素细节。
- 使用同一标记排版 1280 × 480 的仓库横幅。上表提供原尺寸 PNG，另附归一化到 512 × 512 的透明标记。
