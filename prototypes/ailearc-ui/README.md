# AileArc 交互原型

2026-10-22：该界面也由独立 .NET/WebView2 桌面验证宿主复用。只有在宿主固定的本地来源中启用受限消息桥接，读取真实归档元数据；普通浏览器预览仍为示例模式。桌面模式禁用未接入的写入/外部打开功能，详见 [桌面验证记录](../../docs/Desktop_UI_Validation.md)。

2026-10-21。以用户选择的第 1 版三栏布局为主，融合第 2 版的精简顶部、多选框和暖色倾向。**这不是生产客户端，也不是最终技术选型。**

## 试用

```powershell
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

浏览器打开 http://127.0.0.1:4173/ 。构建：`npm run build`。

交互辅助逻辑测试：`npm test`。

可体验：

- 左侧目录、双击进入文件夹、上一级、前进/后退、面包屑、最近打开示例；返回时恢复搜索、排序和选择。
- 搜索整个压缩包、空结果、列排序。
- 行复选框、全选/半选、Ctrl/Command 多选、Shift 连选、方向键/Home/End、Space/Enter、Ctrl+F、Ctrl+A 和 Alt+左右；更多菜单可查看快捷键。
- 单选文件属性、多选摘要、可收起的详情栏。
- 解压的逐项目标路径预览与结构切换、输入错误提示、模拟进度/完成/取消和任务详情；任务期间不允许启动第二个模拟任务。
- 新建 ZIP/7Z 的最终名称预览（避免重复扩展名）、非法名称提示、移除已添加源项目。
- 用户已选择暖石墨作为默认主题。外观菜单保留暖石墨、配套浅色和紧凑行高；暖金只保留设计参考图。

示例压缩包使用同一组虚构数据；外部打开、编码切换、副本另存、解压和创建均为模拟，不调用真实引擎或读写用户文件。设置仅存在当前页面，刷新重置。

## 设计依据

- `reference/layout-option-1.png`：已选择的三栏结构。
- `reference/palette-option-2.png`：精简和暖色参考。
- 比较源图时应叠加用户最新要求：顶部缩减、常显复选框、暖色，不按原图冷色和重复工具栏做逐像素复刻。
- [design-qa.md](design-qa.md) 记录本地浏览器检查。`qa-evidence/` 是本地验证截图，Git 忽略。
- 系统字体栈与 Phosphor 图标（MIT），不嵌入 DBX 截图或私有数据。React/Vite 用于快速验证交互，不决定最终桌面框架。

本原型没有部署公开站点，也不创建正式 Release。
