# AileArc · 折页标识

第二版保留折页 A 的识别轮廓，按图像生成探索稿重绘矢量：将两侧尖角和分离的底边改为连续回折的纸带，缩小中央纸页，保留负空间。深浅字标、应用图标和宣传图统一使用同一折带。

| 用途 | 文件 |
|---|---|
| 应用图标、头像 | mark.svg、mark.png（512 × 512）、AileArc.ico（16–256 px） |
| 标识叠放在深底图片上 | symbol.svg（透明底） |
| 浅底单色印刷 | mono.svg（透明底） |
| 带名称的横向组合 | lockup-dark / lockup-light，均有 SVG 与 608 × 160 PNG |
| 仓库、项目介绍、宣传横幅 | banner.svg、banner.png（1280 × 480） |
| 英文社交分享卡片 | social.svg、social.png（1200 × 630） |
| Windows 身份包 | package-150.png |

石墨 #25221F，纸页 #F4E3C3，折面 #D4AE6C，铜色 #C48463。窄空间使用方形图标，不压缩横幅。SVG 是可编辑源稿，PNG 用于固定排版。在仓库根目录运行 export.cjs 文件头的两条命令可以重新导出 PNG 和多尺寸 ICO；导出工具不是客户端运行依赖。仓库 MIT 许可证适用于本项目原创图形。
